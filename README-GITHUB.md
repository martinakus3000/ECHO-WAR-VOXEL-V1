# ECHO//WAR Voxel

Prototip jugable d'un FPS voxel amb bucles temporals. Cada derrota grava la ruta del jugador i crea un eco que repeteix els seus moviments i dispars en el següent intent.

## Característiques

- Moviment amb WASD o fletxes i esprint amb Shift.
- 8 bots amb moviment, persecució i atac.
- Tres armes: ballesta, arc ràpid i canó de bloc.
- Ecos temporals, recàrrega, pols temporal i portal final.
- Estètica voxel inspirada en jocs de blocs.

## Executar

En Windows, obre `INICIAR-JOC.bat`. També es pot iniciar amb `npm install` i `npm run dev`.
